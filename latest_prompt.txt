What's done:
- Auth (magic link + Google OAuth), event discovery, attendance, reviews with photo uploads, venue/artist rating pages, XSS sanitization, leaderboard pages (Top Venues / Top Artists), pagination for venues/artists, E2E tests, client-side rate limiting on mutations, 86 unit tests passing, 0 lint errors

What to build — Phase A: Social Proof (in order):

A1. Artist Follow System
- New migration 007_artist_follows.sql: artist_follows table (id, user_id FK → auth.users, artist_id FK → artists, created_at), UNIQUE(user_id, artist_id), RLS policies (owner CRUD, public read)
- API hooks in features/artists/api/artists.ts: useFollowArtist, useUnfollowArtist, useIsFollowingArtist, useFollowedArtists
- "Track Artist" button on ArtistDetailPage (heart/star toggle, optimistic update)
- "Tracked Artists" tab on MyGigsPage showing followed artists with upcoming events

A2. Venue Follow System
- Same migration 007: venue_follows table (id, user_id, venue_id, created_at), same RLS pattern
- API hooks in features/venues/api/venues.ts: useFollowVenue, useUnfollowVenue, useIsFollowingVenue, useFollowedVenues
- "Track Venue" button on VenueDetailPage
- "Tracked Venues" tab on MyGigsPage

A3. User Follow System
- Same migration 007: user_follows table (id, follower_id, following_id, created_at), UNIQUE(follower_id, following_id), check(follower_id != following_id), RLS policies
- API hooks in features/profile/api/follows.ts: useFollowUser, useUnfollowUser, useIsFollowingUser, useFollowers, useFollowing
- Follow/unfollow button on PublicProfilePage
- Follower and following counts displayed on profile

A4. Review Reactions
- Same migration 007: review_reactions table (id, user_id, review_id, reaction_type ENUM('like','helpful','love'), created_at), UNIQUE(user_id, review_id, reaction_type), RLS policies
- API hooks in features/reviews/api/reviews.ts: useReactToReview, useRemoveReaction, useReviewReactions
- Reaction buttons (👍 Helpful ❤️ Love 🔥 Like) on PublicReviewPage and EventDetailPage review cards with counts

A5. Activity Feed
- New route /feed with FeedPage component
- New hook useActivityFeed() that queries: recent public reviews from followed users, recent events from tracked artists/venues (via attendance), recent reviews on tracked venues/artists
- Paginated feed with cards showing: review summary + rating, event announcement, "X is going to" activity
- Add "Feed" link to main nav in Layout.tsx
