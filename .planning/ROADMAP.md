# Project Roadmap — RateMyGig

## Milestone: Social Proof & Engagement

**Status:** Phase A Complete

### Phase A: Social Proof

**Goal:** Add social features (follows, reactions, activity feed) that multiply the value of existing content and create network effects between users, artists, and venues.

**Requirements:** [A1, A2, A3, A4, A5]

**Plans:** 3 plans

Plans:
- [x] A-01-PLAN.md — Database schema + API hooks for all social features (Wave 1)
- [x] A-02-PLAN.md — Follow UI on detail pages + MyGigs tracked tabs (Wave 2)
- [x] A-03-PLAN.md — Review reaction UI + Activity feed page (Wave 2, parallel to A-02)

---

### Phase B: Setlist Archive
**Goal:** Community wiki-style setlists for events — find out what was played, add your own, see artist song statistics.

Plans:
- [x] B-01-PLAN.md — Database schema + API hooks for setlists and songs (Wave 1)
- [x] B-02-PLAN.md — Setlist viewer & editor UI (Wave 2)
- [x] B-03-PLAN.md — Setlist statistics & artist song pages (Wave 2, parallel to B-02)

---

### Phase C: Discovery Intelligence
**Goal:** Personalized recommendations, geolocation, enhanced search, and notification foundation.

Plans:
- [x] C-01-PLAN.md — Database schema, RPC functions, and API hooks for discovery features (Wave 1)
- [x] C-02-PLAN.md — Discovery UI enhancements (Wave 2)
- [x] C-03-PLAN.md — Preferences & Notifications UI (Wave 2, parallel to C-02)

---
### Phase D: Profile & Lists
**Goal:** Enrich profiles (avatar upload, social links, gig stats), add custom lists/collections, review comments, and draft reviews.

Plans:
- [x] D-01-PLAN.md — Database schema, storage, and API hooks for avatars, comments, lists, drafts (Wave 1)
- [x] D-02-PLAN.md — Profile enrichment UI (Wave 2)
- [x] D-03-PLAN.md — Lists & comments UI (Wave 2, parallel to D-02)
